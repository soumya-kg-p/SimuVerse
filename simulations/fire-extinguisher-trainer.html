    2. Core logic in this file

    • Extinguishers: makeExt(kind) builds water / CO₂ / ABC powder with pin, lever, hose, gauge. EFF[fireClass][kind] is the suitability matrix (water on a liquid fire is −0.6: it spreads the fire).
    • PASS: pick up → first trigger pull removes the pin → aim: ray from the nozzle hits the floor at P → squeeze (hold trigger) → sweep: lateral movement of P across the pool.
    • Fire: 5×5 cells; each burns, spreads to neighbours and grows. A stream only reduces cells within 0.3 m of P, so a static aim cannot win: you must sweep. Range 1–4.5 m is full effect; too close is splash and heat.
    • Score (100): type 25 % · aim at base 30 % · sweep 20 % · time 25 % (full marks ≤ 20 s, zero at 90 s) minus burn penalty for standing in the heat.

    3. Step-by-step expansion

    1. Replace boxes with glTF models (GLTFLoader), bake lighting, keep 72 Hz on Quest.
    2. Add scenarios as data: {room, fireClass, startHeat, hazards, passMark}; load from JSON, randomise per attempt.
    3. Add a briefing step: read the hazard placard, inspect the gauge (tooltip), check the tamper seal, plan an escape route (stay between fire and exit).
    4. Add failure branches: cylinder empties, fire reaches the shelves, smoke layer lowers (fade vision), alarm and evacuation step.
    5. Add Class C (electrical) and Class K (kitchen) fires and a wet-chemical extinguisher; spread rules per class.
    6. Hand tracking: grab with pinch (XRHand), pull the pin with the other hand; haptics via gamepad.hapticActuators on pin pull and discharge.
    7. Instructor mode: stream scores over WebSocket, replay recordings, heat-map of where the stream hit.
    8. Package: PWA + HTTPS (WebXR needs it), then optional Unity port using the same data files.
